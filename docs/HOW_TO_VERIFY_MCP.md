# How to Verify a GitHub MCP Workflow

1. Use a personal repository and the minimum required GitHub permissions.
2. Keep tokens outside version control.
3. Start with a read-only request for repository or pull-request metadata.
4. Compare the MCP result with the GitHub page.
5. Record the request, response summary, verification, and access limitations.
6. Do not post comments, merge code, or change repository state solely to create evidence.
