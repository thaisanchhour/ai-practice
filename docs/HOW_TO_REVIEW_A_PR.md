# How to Record an AI Assisted Pull Request Review

1. Open a real pull request and capture its URL and commit range.
2. Ask the AI coding assistant to review correctness, security, maintainability, and tests.
3. Verify each finding against the diff and relevant tests.
4. Mark each finding accepted, rejected with a reason, or deferred.
5. Apply accepted fixes in a separate commit.
6. Run the relevant checks and preserve their output.
7. Complete the matching form in `docs/reviews` with the actual date and tool name.
